Changelog

July 2026

⚒️

Anvil is born

Renamed from machin-colibri to machin-anvil: a pure-MFL LLM runtime with zero runtime deps, OpenAI-compatible serving, and honest certifications — built to host coding agents on cheap CPUs.

🚀

Agentic model family

Llama-3.2-1B (~21 tok/s), xLAM-1b function-calling, Qwen2.5/Qwen3 with streaming + tools, Q4 VNNI (~19.6 tok/s), and Ternary-Bonsai-1.7B Q2 with a 12/12 tool-selection bench over 20 tools.

🧰

Tool calling that agents can use

tool_choice: "required", prefix cache for multi-turn system prompts, SSE streaming, and forced-prefix decoding so clients like pi/tau get real tool_calls instead of prose.

📦

Smaller footprints, same honesty

Int4 Qwen3 (half size), ternary Bonsai (~462 MB), embeddings (Qwen3-Embedding-0.6B with parity cert), idle madvise release, and KV warm/persist so restarts skip the cold prefill tax.
