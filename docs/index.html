What you get

  • Pure MFL engine — no BLAS, ggml, or PyTorch at runtime
  • OpenAI /v1 — chat, SSE, tools, embeddings
  • Prefix cache + warm KV — agent system prompts stay cheap after turn 1
  • Cert trail — every claim has a measured write-up under certs/

Reference HW: Intel i5-13400T + DDR4 (rbm21). See ROADMAP.md for the path to a tagged stable pair.
